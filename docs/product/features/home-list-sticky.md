# Product Feature: 首页行程列表与分层吸顶

## Description
首页列表模式按日期连续展示行程。行程标题和地图模式同款日期时间轴固定在顶部；当前日期标题滚动到时间轴下方后吸附，并由相邻日期标题推入替换。

## Inputs
- 当前共享行程标题与按日期排序的 `TripDaySnapshot`。
- 地图模式正在使用的日期时间轴组件、今日基准与选中日期。
- 每日按开始时间排序的行程卡片。

## Outputs
- 长图式紧凑分日列表。
- 固定的行程标题与日期时间轴。
- 可推替的“MM.dd 星期＋当日摘要”日期标题。

## Boundary
### Included
- 列表与地图调用同一个时间轴组件，保持日期文本、今日标识、横向滚动、居中锚点和点击选择一致。
- 点击时间轴日期滚动到对应日期；纵向滚动进入新日期时更新时间轴选中态。
- 行程标题和时间轴固定；每日标题只固定在时间轴下方，并由相邻日期标题推替。
- 保留卡片详情、行程/日期/卡片编辑与地图切换入口。
- 长按卡片后可在同一天内排序，也可拖入其他日期；拖动卡片保持不透明并略微放大，目标位置的卡片先让出一个卡位作为提示。松手前不改变数据与路线，落位后才保存源日/目标日的 `position`。跨日时还会同步目标 `dayId`，并将开始/结束时间按日期差整体平移，再按两个日期的新相邻关系展示/计算路线段。
- 同日排序不显示单张卡片橙色描边，只以卡位间隙提示插入点；拖入其他日期时，仅对目标日期的整组行程显示橙色边框。
- 松手落位时继续保留根层卡片副本，从手指松开位置飞向新布局位置；动画结束后再显示列表中的真实卡片，不能从拖动前的原位置重新起飞。
- 拖动副本位于列表页面根层，始终覆盖吸顶日期标题、其他卡片和路线。只有长按成功后继续移动才进入拖卡状态；直接从卡片开始上下滑动仍滚动页面。拖卡靠近列表可视区域上下边缘时自动滚动，越靠近边缘速度越快，并限制在可控速度范围内；即使原卡片随页面滚出渲染区域，拖动状态也必须保持到用户松手。
- 列表卡片由后端 `showLargeImage` 明确选择形态：高质量横向封面使用带 12pt 内边距的沉浸式大图与底部渐变信息层；有描述、备注或提示时，图片下方继续显示独立深色摘要区，没有摘要时不保留空白。其余卡片使用 64pt 封面、单行标题、SVG 时间/价格信息和独立深色摘要区。客户端不得仅凭“有图片”自行展示大图。
- 卡片左侧 4pt 橙色条是时间状态，不是拖动状态：全行程只标记当前正在进行的活动；当前无进行中活动时标记紧接下来的第一项。拖动副本保持对应活动原有时间状态。
- 仅列表模式支持卡片左滑操作：灰色编辑、橙色 Agent 对话、红色删除三个操作从滑动开始按 1:1:1 同步展开，最终各为 68pt；一次只展开一张。编辑进入现有卡片编辑器；Agent 对话打开现有旅行 Agent 并预填当前卡片上下文，不自动发送；删除继续使用二次确认和现有本地/云端同步流程。三个按钮均使用资产目录内的 SVG 图标。

### Excluded
- 不允许客户端写入图片评分或大图决策；`imageScore` 与 `showLargeImage` 均由服务端寻图任务维护。
- 不为“当日总结”新增持久化字段；本次由现有卡片标题生成简短摘要。
- 不包含 iPad、横屏专属布局或发布 TestFlight。

## Acceptance Criteria
- 列表模式能呈现全部日期与卡片，日期和卡片顺序与现有数据一致。
- 行程标题与地图同款时间轴在整个纵向滚动过程中保持可见、互不遮挡。
- 任一日期标题到达时间轴下缘后固定，下一/上一日期标题到达时平滑替换。
- 点击时间轴任意日期，目标日期标题滚动并停在时间轴下方。
- 手势滚动跨日后，时间轴选中态切换为当前吸顶日期。
- 长按并拖动卡片到同日或其他日期的指定位置后，列表按新顺序稳定显示；重进页面后日期归属和顺序不丢失，路线距离/时长对应两个受影响日期的新前后相邻卡片。
- 拖动松手后，悬浮卡片从实际松手位置移动到最终卡位；过程中原位置和目标位置都不出现第二张同卡片或错误起飞动画。
- 普通触摸卡片后上下滑动不会被拖动手势拦截；拖卡过程中卡片不被标题或内容遮挡；手指进入上下边缘阈值后页面连续滚动，移动回中间区域后停止自动滚动。
- 卡片横向左滑时同步展开编辑/Agent/删除操作，纵向移动仍滚动页面；点击编辑打开对应卡片，点击 Agent 后输入框预填当前卡片的日期、标题、时间和地点，点击删除先显示确认框，未确认时不改变数据。
- 高分横向封面卡片显示为大图；有待办内容时在图片下方显示摘要面板，无待办时卡片紧贴图片收口。低分、无图或旧缓存卡片保持普通卡片；同一时刻最多一张卡片显示左侧橙色当前/下一项指示条。
- 地图/列表入口、详情和编辑操作仍可用；空日期与加载/错误状态仍有可理解反馈。

## Data And Permissions
- Data touched: 客户端只读使用 `TravelCardSnapshot.imageScore/showLargeImage`；编辑动作继续走现有 `SyncEngine`。后端寻图任务写入卡片的服务端拥有字段。
- Owner: 现有共享行程成员。
- Permission/auth expectations: 沿用现有本地模式、登录、共享权限和同步约束。

## UX Notes
- Screens/pages: 首页的详细行程/列表模式。
- Empty/loading/error states: 沿用现有无旅程、未配置、无日期、加载、离线和失败状态。
- Human verification: 在小屏 iPhone 模拟器上长距离上下滚动，点击多个时间轴日期，并在地图/列表间往返切换。

## Open Questions
- 无阻塞问题；参考图中的“8字当日总结”没有现有字段，本次明确采用卡片标题派生展示。
