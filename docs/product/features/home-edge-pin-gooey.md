# Product Feature: 首页吸边 Pin 动态边界、无重叠聚合与 Gooey 过渡

## Description
首页地图中的 Pin 只在完整视觉外框进入指定安全区时保持普通位置；一旦越界便吸附到安全区边缘。屏内或边缘 Pin 的实际外框重叠时合并，方向足够分离且拆分后不重叠时才拆开。既有 placement resolver 仍是聚合、拆分、成员身份和最终位置的唯一权威；仅当 resolver 输出的成员集合发生独立到聚合或聚合到独立的变化时，在稳定形态之间播放短暂、可逆的 Gooey 融合/分离视觉过渡。

## Boundary

### Included
- 安全区：左/右 20pt、上 160pt。
- POI 覆盖层显示时，下边界为时间轴上边缘减 20pt，并跟随卡片高度动画。
- 时间轴和卡片整体收起时，下边界为浮动 Tab Bar 上边缘减 20pt。
- 上/下边缘只有左、右两个端点槽位；越过屏幕中心立即换槽并与目标槽聚合。
- 上左、上右、下左、下右分别保留对应的一个直角作为指向。
- 卡片或整体覆盖层改变安全区时，吸边 Pin 平滑移动到新边界；圆形 Pin 进出上下吸边状态时，指向直角随形状动画长出或收回。
- 屏内、边缘及两者交界处使用实际渲染外框做传递碰撞合并。
- 超宽聚合用稳定前缀加 `+N`，所有成员 ID 保留。
- 动态安全区高度不足以容纳高亮双圆时，临时降级为 32pt 数字 Pin；空间恢复后恢复高亮样式。
- Swiper 切换、POI 卡片点击等自动定位会保留目标 POI 身份；默认倍率仍聚合时继续放大，直到目标成为独立 Pin，非重复坐标不会停在聚合态。
- 屏内、边缘及两者交界的成员集合由独立变为同一 placement 时，旧 Pin 表面向 resolver 给出的最终聚合胶囊做 Gooey 融合；由同一 placement 拆成多个 placement 时播放对应的反向分离过渡。
- Gooey 方向使用源 Pin 与最终 placement 的真实屏幕坐标连续计算，覆盖完整 360°；不提供首页方向选择或直接拖动 Pin 的交互。
- Gooey 只作用于白色 Pin 背景表面；数字、`+N`、类别图标和最终橙色描边使用独立清晰层。高亮类别圆不参与永久融合，在进入聚合时退出，在目标成员拆出且仍被选中时恢复。
- 过渡中的临时视觉层不可点击、不进入 VoiceOver 辅助功能树；点击、选择、自动追焦和其他业务操作始终使用 resolver 的最新最终成员结果。
- 初始加载、POI 新增/删除/重排、纯选择变化、成员集合不变的普通/吸边位置切换、动态安全区平移或标签宽度变化不触发 Gooey。地图拖拽、缩放、自动追焦或安全区变化若确实改变成员集合，则正常触发。
- Reduce Motion 开启时不播放 Gooey、拉伸或替代性弹簧/缩放动画，直接显示 resolver 最终形态；若在过渡中开启，则取消临时效果并立即收敛到最新终态。

### Excluded
- 为避免重叠而沿边移动 Pin。
- 后端、路线、POI 数据、相机、导航和持久化修改。
- 修改既有碰撞闭包、边缘角度/投影滞回、聚合/拆分阈值、成员顺序、代表 ID、标签、选择态或 placement 最终位置。
- 首页 Pin 直接拖拽、生产环境调参面板、实时角度/间距指标，以及把 Demo 的融合阈值或辅助吸附动作接入首页。
- 初始加载或数据 CRUD 的虚构融合动画、跨屏长尾、常驻 Gooey 滤镜，以及新的声音、触觉、埋点或第三方 Gooey 依赖。

## Acceptance Criteria
- 完整外框满足 `minX >= 20`、`maxX <= screenWidth - 20`、`minY >= 160`。
- 覆盖层显示时 `maxY <= timelineTop - 20`；整体收起时 `maxY <= tabBarTop - 20`。
- 卡片展开/收起与整体覆盖层展开/收起期间，边缘 Pin 随动态边界重算并连续移动，不瞬移。
- 地图拖动时 Pin 位置保持跟手；跨越上下吸边阈值时仅形状做圆角/直角插值。
- 上下边没有中间横向位置，只存在左右端点；跨中心后直接进入另一端。
- Pin 不通过邻居挤位；若最终外框相撞则合并。拆分结果必须两两不重叠且成员不丢失。
- 左右边非碰撞 Pin 使用从物理屏幕中心指向 POI 的射线交点；安全区不包含屏幕中心时仍不丢 Pin。
- 屏内 Pin 的真实外框重叠同样合并，包括高亮 Pin；高亮类别图标和样式保留。
- resolver 输出从多个独立 placement 变为一个多成员 placement 时，只播放一次向最终聚合胶囊收敛的 Gooey 融合；反向成员集合变化播放对应分离，且两者不改变 resolver 结果。
- 水平、垂直、斜向及跨越 359°/0° 的融合/分离连续，无方向翻转、NaN、断桥或错误侧汇入。
- 动画中途反向或收到更新的 placement 时，从当前可见 presentation 状态重定向，不回跳起点、不排队播放过时动画、不闪现旧成员。
- 多成员同帧合并或拆分时，所有成员确定性地汇入或离开同一最终表面；最终成员 ID、顺序、代表 ID、标签和选中身份与无动画 resolver 输出完全一致。
- 稳态样式保持现状：普通数字 Pin 与聚合 Pin 高 32pt，聚合宽度随标签变化；选中单 Pin 保留类别圆、数字圆和橙色描边。
- 圆形 Pin 与上左、上右、下左或下右端点 Pin 融合/分离时，端点 Pin 的外侧指向直角从过渡第一帧到最后一帧始终保持为直角，不得先圆化、消失后再恢复；Gooey bridge 只能连接非指向表面。
- Gooey 仅过滤白色背景，数字、`+N`、类别图标和最终橙色描边全程可辨；高亮成员进入聚合时类别圆平稳退出，拆出且仍选中时恢复，聚合稳态不新增类别圆。
- 初始加载、CRUD、纯选择、成员集合不变的平移/吸边/标签变化不触发 Gooey；由拖拽地图、缩放、自动追焦或安全区变化造成的真实成员集合变化会触发。
- 地图连续拖动或缩放时 Pin 保持跟手；Gooey 不等待手势结束、不抢占地图手势，临时层不可交互且不会新增辅助功能元素或造成一次点击命中多个 Pin。
- Reduce Motion 开启时直接呈现最新最终形态，无 Gooey、拉伸、弹簧、缩放或循环淡入淡出；运行中切换 Reduce Motion 也不会留下残影或旧状态。
- Gooey 滤镜外框受动态安全区约束；四边、四角、超宽标签和高亮形态均不被时间轴、卡片或 Tab Bar 裁切，拉丝超过有效视觉距离时不得形成跨屏长尾。
- 无活动融合/分离时不保留刷新循环或常驻滤镜；过渡完成、取消或重定向后清理临时图层、计时器和离屏资源，快速往返 100 次后资源数量不持续增长。
- 典型上限或至少 30 个可见 Pin、最多 4 组同时过渡时，60Hz 参考设备上的地图交互目标不低于约 55fps，Gooey 增量主线程耗时 p95 不超过 4ms，10 秒连续 pan/zoom 无超过 100ms 的 Gooey 主线程阻塞；无法满足时优先减少模糊或并发效果，最终降级为直接终态而不降低地图响应。
- 任意有效的 32pt 以上安全区都不丢成员。
- 自动定位只检查目标 POI 所属 placement；独立后立即停止继续放大，用户手动拖动或缩放会取消未完成的自动追焦。

## Verification
- 保留现有 40 项纯几何/聚合单元测试，继续覆盖安全边界、动态 Tab Bar fallback、位置过渡、圆角/直角映射、自动追焦倍率上限、上下端点切换、碰撞闭包、超宽标签、屏幕中心位于安全区外和高亮尺寸；加入 Gooey 后这些 resolver 结果不得变化。
- 新增自动测试覆盖普通、边缘及 regular/edge 交界的 merge/split 触发判定，至少八个代表角度和 359°/0°，多成员确定性、成员守恒、选中类别圆、动画中途反向、初始加载/CRUD/纯选择/纯平移不触发、Reduce Motion 直接终态，以及临时层完成和取消后的清理。
- iPhone 17 Pro 模拟器或真机人工验证连续 pan/zoom、自动追焦去聚合、卡片/整体覆盖层展开收起、四个边缘与四角、选中态、超宽标签和快速往返阈值；每次过渡结束后只保留当前稳定 Pin，无 Gooey 尾巴、残影、重复命中或辅助功能重复元素。
- 使用 Instruments 或等价性能采样验证至少 30 个可见 Pin、最多 4 组同时过渡与快速往返 100 次的帧率、主线程阻塞和资源清理；若触发性能降级，最终 placement、成员和交互结果必须保持一致。
