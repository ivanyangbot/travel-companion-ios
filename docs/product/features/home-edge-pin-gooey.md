# Product Feature: 首页吸边 Pin 动态边界与无重叠聚合

## Description
首页地图中的 Pin 只在完整视觉外框进入指定安全区时保持普通位置；一旦越界便吸附到安全区边缘。屏内或边缘 Pin 的实际外框重叠时合并，方向足够分离且拆分后不重叠时才拆开。界面不再展示 gooey 拉丝或尾巴。

## Boundary

### Included
- 安全区：左/右 20pt、上 160pt。
- POI 覆盖层显示时，下边界为时间轴上边缘减 20pt，并跟随卡片高度动画。
- 时间轴和卡片整体收起时，下边界为浮动 Tab Bar 上边缘减 20pt。
- 上/下边缘只有左、右两个端点槽位；越过屏幕中心立即换槽并与目标槽聚合。
- 上左、上右、下左、下右分别保留对应的一个直角作为指向。
- 卡片或整体覆盖层改变安全区时，吸边 Pin 平滑移动到新边界；圆形 Pin 进出上下吸边状态时，指向直角随形状动画长出或收回。
- 屏内、边缘及两者交界处使用实际渲染外框做传递碰撞合并。
- 超宽聚合用稳定前缀加 `+N`，所有成员 ID 保留。
- 动态安全区高度不足以容纳高亮双圆时，临时降级为 32pt 数字 Pin；空间恢复后恢复高亮样式。
- Swiper 切换、POI 卡片点击等自动定位会保留目标 POI 身份；默认倍率仍聚合时继续放大，直到目标成为独立 Pin，非重复坐标不会停在聚合态。

### Excluded
- Gooey/metaball 动画或连接桥。
- 为避免重叠而沿边移动 Pin。
- 后端、路线、POI 数据、相机、导航和持久化修改。

## Acceptance Criteria
- 完整外框满足 `minX >= 20`、`maxX <= screenWidth - 20`、`minY >= 160`。
- 覆盖层显示时 `maxY <= timelineTop - 20`；整体收起时 `maxY <= tabBarTop - 20`。
- 卡片展开/收起与整体覆盖层展开/收起期间，边缘 Pin 随动态边界重算并连续移动，不瞬移。
- 地图拖动时 Pin 位置保持跟手；跨越上下吸边阈值时仅形状做圆角/直角插值。
- 上下边没有中间横向位置，只存在左右端点；跨中心后直接进入另一端。
- Pin 不通过邻居挤位；若最终外框相撞则合并。拆分结果必须两两不重叠且成员不丢失。
- 左右边非碰撞 Pin 使用从物理屏幕中心指向 POI 的射线交点；安全区不包含屏幕中心时仍不丢 Pin。
- 屏内 Pin 的真实外框重叠同样合并，包括高亮 Pin；高亮类别图标和样式保留。
- 不存在 gooey 尾巴、桥接图层或拆分过渡状态。
- 任意有效的 32pt 以上安全区都不丢成员。
- 自动定位只检查目标 POI 所属 placement；独立后立即停止继续放大，用户手动拖动或缩放会取消未完成的自动追焦。

## Verification
- 40 项纯几何/聚合单元测试覆盖安全边界、动态 Tab Bar fallback、位置过渡、圆角/直角映射、自动追焦倍率上限、上下端点切换、碰撞闭包、超宽标签、屏幕中心位于安全区外和高亮尺寸。
- iPhone 17 Pro 模拟器验证整体覆盖层展开/收起及选中态无 gooey 残留。
