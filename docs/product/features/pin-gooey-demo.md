# Product Feature: Pin Gooey 视觉调参 Demo

## Description
设计或开发人员可在 App 内打开一个与业务隔离的实验页，分别自由拖动单体圆 Pin 与聚合胶囊 Pin，观察两者在任意相对位置、完整 360° 方位上的液态轮廓及数字成员融合/分离，并实时调整 Gooey 参数。聚合 Pin 与首页一致，按当前数字文字宽度自动伸缩。Demo 提供 `2.3.7.5.4` 的 `4` 从右侧分离和 `7.3.8.12` 的 `3` 从左上方分离两个静态场景。

## Inputs
- 单体圆 Pin 的二维拖拽位置。
- 聚合胶囊 Pin 的二维拖拽位置。
- 静态数字场景选择；初始成员顺序由场景内相对位置稳定推导，后续融合按单体 Pin 的实际进入方位更新插入槽位。
- 当前融合/分离数字内容；聚合 Pin 复用首页 16pt medium 字体、20pt 总水平留白和最小 32pt 宽度规则，两类 Pin 高度固定为 32pt。
- 模糊半径、Alpha 阈值、源不透明度、描边、阴影。
- 融合阈值、分离阈值、辅助分离距离、弹簧响应和阻尼。

## Outputs
- 两个 Pin 在舞台中的实时位置、液态轮廓、数字成员位置、融合状态、真实表面间距和连续方位角。
- 融合态显示完整有序数字串；分离态显示保持顺序的剩余聚合数字和被抽取的单体数字。
- 关闭页面或恢复默认前，两个 Pin 保持用户自由拖动后的落点。

## Boundary
### Included
- 独立本地 Demo sheet、双 Pin 二维自由拖动、连续 0°..<360° 布局、实时参数面板和恢复默认。
- 两个静态数字成员场景、空间排序、稳定成员身份，以及融合/分离区间内连续的成员槽位插值和分隔符交叉淡变。
- 复用首页白色 32pt Pin、橙色选中描边和黑色舞台的视觉语言。
- 辅助功能可分别选择两枚 Pin，并提供上下左右移动及融合/分离动作。
- 本页面是 App 内唯一允许呈现 Gooey 的界面；只复用静态视觉 token，不接入首页 placement、resolver、MapLibre annotation 或地图事件。

### Excluded
- 首页 MapLibre Pin 的聚合、拆分、吸边或业务行为修改。
- POI、行程、地图、业务数字、图标、网络、后端、持久化、统计或发布。
- 自动把手指落点吸附到四个方向；普通拖拽松手后不得改变用户落点。

## Acceptance Criteria
- 从底部齿轮可打开并关闭独立 Demo，正式主 Tab 选择不被改变。
- 页面不读取业务模型、不发网络请求；Pin 内只显示两个内置静态数字场景，不读取首页或行程数字。
- `2.3.7.5.4` 中的 `4` 从右侧分离后，聚合 Pin 显示 `2.3.7.5`，单体 Pin 显示 `4`。
- 将 `4` 绕到聚合 Pin 左侧再融合时，完整数字顺序显示 `4.2.3.7.5`；从右侧融合时仍显示 `2.3.7.5.4`。
- `7.3.8.12` 中的 `3` 从左上方分离后，聚合 Pin 显示 `7.8.12`，单体 Pin 显示 `3`。
- 聚合数字顺序由成员相对位置确定，输入数组顺序改变不得改变最终空间顺序；从融合态向外拖到分离阈值前保持原槽位，越过分离阈值后解除锁定，再次靠近时必须按单体 Pin 当前相对方位重新计算槽位。
- 被抽取数字从其融合态槽位连续移动到单体圆心；剩余数字以稳定身份连续补位，融合状态或阈值切换时不得离散跳变。
- 两个 Pin 尚未形成可见 Gooey 连接时，被抽取数字必须完整停留在单体 Pin 圆心；进入由模糊、Alpha、描边和融合阈值共同决定的短连接区间后才开始移动，不能提前飞出圆形 Pin。
- 舞台包含单体圆 Pin 和聚合胶囊 Pin；两个 Pin 都有独立的二维拖拽命中区。
- 拖动任一 Pin 时另一 Pin 保持当前位置；水平、垂直和斜向位移均真实作用，不投影到固定轴。
- 两 Pin 中心连线连续覆盖 0°..<360°；跨越 359°/0° 和中心重合时不跳变、不产生 NaN。
- 聚合胶囊保持水平；单体与聚合 Pin 高度始终为 32pt，聚合宽度随当前显示数字连续变化并与首页文字测量结果一致，不提供固定总宽度。
- 融合状态由单体圆到聚合胶囊中心线段的二维最短表面间距驱动；长边、端部和斜角连续一致。
- 融合/分离双阈值作用于真实表面间距；滞回区保持上次状态且任意角度不闪烁。
- 普通拖拽松手后保留当前二维位置；恢复默认和辅助功能融合/分离动作可使用可调弹簧。
- 两个完整滤镜外框受舞台边界约束；拖到四边和四角不越界、不裁切。
- 聚合宽度或滤镜 padding 改变导致合法区域缩小时，两枚 Pin 各自 clamp 到最近合法位置，不重置方向。
- 完全融合时仍能拖出单体 Pin；聚合 Pin 的可见区域也可单独拖动。
- 一次拖拽开始后锁定当前 Pin，移动到另一 Pin 附近或穿过其透明命中区时不得停住或切换目标；松手后才恢复重叠区的单体 Pin 优先命中。
- 聚合 Pin 自适应宽度变化期间，活动拖拽以手势开始时的物理圆心为固定锚点；靠近单体 Pin 时不得因中心边界重映射或布局补偿而减速、停住或被推回。
- 模糊、Alpha 阈值、源不透明度、描边、阴影、辅助分离距离、双阈值、弹簧响应和阻尼均可调且即时生效；聚合宽度由内容自动决定。
- 恢复默认同时恢复全部参数、右侧数字场景、标准水平分离坐标和分离状态。
- 自动测试覆盖两个数字场景的空间顺序、分离结果、成员身份与过渡连续性，以及至少八个代表角度、0...359° 有限值、两 Pin 分别 x/y 拖动、胶囊真实间距、边界、中心重合、极端宽度和状态恢复。
- 模拟器人工验证两枚 Pin 分别水平、垂直、斜向拖动，并让一枚 Pin 绕另一枚完成完整一周。

## Data And Permissions
- Data touched: 仅 SwiftUI `@State` 中的静态数字场景选择、两枚 Pin 的归一化二维位置、调参和手势状态。
- Owner: 当前设备上的当前 Demo sheet；关闭即丢弃。
- Permission/auth expectations: 无权限、登录、网络或业务数据要求。

## UX Notes
- Screens/pages: 从底部齿轮打开的可关闭 sheet；上方为二维舞台和实时角度/表面间距，下方为参数面板。
- Empty/loading/error states: 无异步数据；位置、尺寸和异常输入通过有限值检查与边界 clamping 保证合法。
- Human verification: 分别验证 `4` 从右侧得到 `2.3.7.5.4`、从左侧得到 `4.2.3.7.5`，以及 `3` 从左上方得到 `7.3.8.12`；分离时剩余数字无跳变。再拖动两枚 Pin 覆盖轴向、斜向、四角和绕行一周，验证极端参数、恢复默认和辅助功能动作。
