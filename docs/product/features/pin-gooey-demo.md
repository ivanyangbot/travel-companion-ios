# Product Feature: Pin Gooey 视觉调参 Demo

## Description
设计或开发人员可在 App 内打开一个与业务隔离的实验页，设置 `2...12` 个可见 Pin 并随机生成位置、单体/聚合样式和 360° 初始分离方位；随后可像首页地图一样拖拽平移、双指缩放并观察越界 Pin 贴边，也可自由拖动每个 Pin，观察液态轮廓及任意单体/聚合 Pin 之间的数字成员融合/分离。一个多数字聚合 Pin 只计为一个可见 Pin；聚合宽度与首页一致，按当前数字文字宽度自动伸缩。

## Inputs
- 单体圆 Pin 的二维拖拽位置。
- 聚合胶囊 Pin 的二维拖拽位置。
- 可见 Pin 数量（`2...12`）和“随机生成布局”动作；数量与每个 Pin 内部的数字成员数无关。
- 当前融合/分离数字内容；聚合 Pin 复用首页 16pt medium 字体、20pt 总水平留白和最小 32pt 宽度规则，两类 Pin 高度固定为 32pt。
- 模糊半径、Alpha 阈值、源不透明度、描边、阴影。
- 融合阈值、分离阈值、辅助分离距离、弹簧响应和阻尼。
- 模拟地图视角的二维平移、`0.5×...3×` 双指缩放与重置视角。
- “手动控制”开关；默认开启，关闭后禁用单个 Pin 直拖，改由地图平移/缩放自动驱动屏幕碰撞、融合与分离。

## Outputs
- 指定数量的可见 Pin、实时位置、共享液态轮廓和当前交互 Pin 对的数字成员位置；主示例额外输出融合状态、真实表面间距和连续方位角。
- 融合态显示完整有序数字串；分离态显示保持顺序的剩余聚合数字和被抽取的单体数字。
- 关闭页面或恢复默认前，两个 Pin 保持用户自由拖动后的落点。

## Boundary
### Included
- 独立本地 Demo sheet、全部可见 Pin 二维自由拖动、连续 0°..<360° 布局、实时参数面板和恢复默认。
- 手动/首页自动两种控制方式；自动方式保留 Pin 世界坐标，仅改变相机投影，不允许直接改动单个 Pin 坐标。
- 本地随机可见 Pin 场景、可配置可见 Pin 数量，以及任意单体/聚合 Pin 对的空间排序、稳定成员身份、连续成员槽位插值和分隔符交叉淡变。
- 复用首页白色 32pt Pin、橙色选中描边和黑色舞台的视觉语言。
- 辅助功能可分别选择两枚 Pin，并提供上下左右移动及融合/分离动作。
- 本页面是 App 内唯一允许呈现 Gooey 的界面；复用首页静态视觉 token 与纯贴边几何，不接入首页 placement/resolver 状态、MapLibre annotation、真实地图或地图事件。

### Excluded
- 首页 MapLibre Pin 的聚合、拆分、吸边或业务行为修改。
- POI、行程、地图、业务数字、图标、网络、后端、持久化、统计或发布。
- 自动把手指落点吸附到四个方向；普通拖拽松手后不得改变用户落点。

## Acceptance Criteria
- 从底部齿轮可打开并关闭独立 Demo，正式主 Tab 选择不被改变。
- 页面不读取业务模型、不发网络请求；Pin 内数字只用于样式展示，不读取首页或行程数字。
- 数量可在 `2...12` 间设置；点击“随机生成布局”后，舞台上的可见 Pin 数量与设置严格一致，一个聚合 Pin 无论包含多少数字都只计为一个。
- 每次生成随机可见 Pin 位置、随机单体/聚合文本及主融合对的 360° 初始方位；生成新布局时保留当前 Gooey 参数并重置拖拽和融合状态。
- 聚合数字顺序由成员相对位置确定，输入数组顺序改变不得改变最终空间顺序；从融合态向外拖到分离阈值前保持原槽位，越过分离阈值后解除锁定，再次靠近时必须按单体 Pin 当前相对方位重新计算槽位。
- 被抽取数字从其融合态槽位连续移动到单体圆心；剩余数字以稳定身份连续补位，融合状态或阈值切换时不得离散跳变。
- 单体 Pin 脱离旧聚合 Pin 后必须能重新选择并插入其他 Pin；拖拽期间数字动画优先跟随当前手指下的 Pin，不得被场内另一对更深的重叠抢走目标。
- 两个聚合 Pin 接近时，两组数字按 Pin 的相对位置保持各自组内顺序并连续合并到未拖动的 Pin；分隔符同步交叉淡变，不得保留两段静态文字相互覆盖。
- 两个 Pin 尚未形成可见 Gooey 连接时，被抽取数字必须完整停留在单体 Pin 圆心；进入由模糊、Alpha、描边和融合阈值共同决定的短连接区间后才开始移动，不能提前飞出圆形 Pin。
- 舞台包含单体圆 Pin 和聚合胶囊 Pin；所有生成的可见 Pin 都有独立的二维拖拽命中区并加入同一 Gooey 图层。
- 拖拽舞台空白区域时，全部 Pin 按世界坐标同步平移；双指缩放时围绕视口中心缩放位置，Pin 本身保持 32pt 屏幕尺寸。
- “手动控制”开启时每个 Pin 可直接拖动；关闭时所有 Pin 命中层停用，舞台手势完整交给模拟地图。缩小时 Pin 自动靠近并融合，放大后自动远离并分离，过程继续使用同一 Gooey 和数字成员动画。
- 从自动方式切回手动方式后，Pin 保留原世界坐标并恢复独立命中；“恢复默认”同时恢复手动控制开启。
- Pin 世界坐标越过舞台物理边界后，复用首页射线投影与固定落点规则贴边；顶部/底部贴边 Pin 保持对应的单直角指向样式，回到视野内恢复全圆角。
- 拖动任一 Pin 时另一 Pin 保持当前位置；水平、垂直和斜向位移均真实作用，不投影到固定轴。
- 两 Pin 中心连线连续覆盖 0°..<360°；跨越 359°/0° 和中心重合时不跳变、不产生 NaN。
- 聚合胶囊保持水平；单体与聚合 Pin 高度始终为 32pt，聚合宽度随当前显示数字连续变化并与首页文字测量结果一致，不提供固定总宽度。
- 融合状态由单体圆到聚合胶囊中心线段的二维最短表面间距驱动；长边、端部和斜角连续一致。
- 融合/分离双阈值作用于真实表面间距；滞回区保持上次状态且任意角度不闪烁。
- 普通拖拽松手后保留当前二维位置；恢复默认和辅助功能融合/分离动作可使用可调弹簧。
- 两个完整滤镜外框受舞台边界约束；拖到四边和四角不越界、不裁切。
- 聚合宽度或滤镜 padding 改变导致合法区域缩小时，两枚 Pin 各自 clamp 到最近合法位置，不重置方向。
- 完全融合时仍能拖出单体 Pin；聚合 Pin 的可见区域也可单独拖动。
- 一次拖拽开始后锁定当前 Pin，移动到另一 Pin 附近或穿过其透明命中区时不得停住或切换目标；松手后才恢复重叠区的单体 Pin 优先命中。
- 聚合 Pin 自适应宽度变化期间，活动拖拽以手势开始时的物理圆心为固定锚点；靠近单体 Pin 时不得因中心边界重映射或布局补偿而减速、停住或被推回。
- 模糊、Alpha 阈值、源不透明度、描边、阴影、辅助分离距离、双阈值、弹簧响应和阻尼均可调且即时生效；聚合宽度由内容自动决定。
- 恢复默认同时恢复全部 Gooey 参数，并按当前可见 Pin 数量重新随机生成样式、坐标和分离状态。
- 自动测试覆盖可见 Pin 数量边界、随机样式/坐标/方向、地图平移缩放、四边贴边与直角、空间顺序、分离结果、成员身份与过渡连续性，以及至少八个代表角度、0...359° 有限值、Pin 分别 x/y 拖动、胶囊真实间距、边界、中心重合、极端宽度和状态恢复。
- 模拟器人工验证两枚 Pin 分别水平、垂直、斜向拖动，并让一枚 Pin 绕另一枚完成完整一周。

## Data And Permissions
- Data touched: 仅 SwiftUI `@State` 中的目标可见 Pin 数量、随机样式、各 Pin 的归一化二维位置、调参和手势状态。
- Owner: 当前设备上的当前 Demo sheet；关闭即丢弃。
- Permission/auth expectations: 无权限、登录、网络或业务数据要求。

## UX Notes
- Screens/pages: 从底部齿轮打开的可关闭 sheet；上方为二维舞台和实时角度/表面间距，下方为参数面板。
- Empty/loading/error states: 无异步数据；位置、尺寸和异常输入通过有限值检查与边界 clamping 保证合法。
- Human verification: 分别设置最小、常用和最大 Pin 数量，多次随机生成并检查数量、方向和顺序确实变化；关闭“手动控制”，确认无法单独拖动 Pin，并通过地图平移/缩放观察自动融合分离。重新开启后检查独立拖动恢复。再让 Pin 分别越过四边检查贴边与顶部/底部直角，并验证数字无跳变、极端参数、恢复默认和辅助功能动作。

## Open Questions
- 无阻塞问题；任何再次接入首页或其他业务页面的提议都必须另开 Feature 并取得明确产品授权。
