## 专有名词

| 名词 | 处理 |
| --- | --- |
| 豆奶（AI 助手） | 中文全部保留「豆奶」；英文用 `Dounai` |
| yunnn（App 显示名） | 所有语言不变 |
| 手书（游记功能名） | 中文保留「手书/手書」；英文用 `journal` |
| 同行（分享扩展名） | zh-Hans 添加到同行 / zh-Hant-TW、zh-Hant-HK 加入同行 / en Add to Trip |

## 粤语（zh-Hant-HK）书写约定

- 口语化用字：嘅（的）、喺（在）、咗（了）、唔（不）、畀（给）、嚟（来）、同（和）、揀（选）、影相（拍照）、而家（现在）
- 词汇随港式惯例：軟件（TW 軟體）、使費（支出）、主頁（TW 首頁）、目前位置
- 保留繁体字形（香港字形标准），标点用全角
